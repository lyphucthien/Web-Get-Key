LPT Hub API and MCP documentation

LPT Hub has a public read-only API for the game list and an MCP server so AI agents can query the same data. No API key or login is needed.

Game list API

GET https://lyphucthien.vercel.app/api/games returns JSON with success, games and errors. Each game has id, name, status (on or soon), type, description, image, order and features (feature groups).

curl -s https://lyphucthien.vercel.app/api/games

The full specification is at /openapi.json (OpenAPI 3.1).

MCP server

Endpoint: https://lyphucthien.vercel.app/mcp (also available at /.well-known/mcp). Streamable HTTP transport; send JSON-RPC with POST; no authentication. There are two read-only tools:

  • list_games: lists supported games, with optional filters status and query.
  • get_key_instructions: the steps to get a key, the wait time, and the key page link.
curl -s https://lyphucthien.vercel.app/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

About keys

Keys are only issued in the user's browser after they complete the short link, so an agent cannot get a key for them. The key-check API is reserved for the LPT Hub script and is not part of the public API.

Files for agents

/llms.txt describes when to use LPT Hub, /sitemap.xml lists the pages, and the home page returns Markdown when you send Accept: text/markdown.
