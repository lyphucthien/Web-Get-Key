Tài liệu API và MCP của LPT Hub

LPT Hub có một API đọc công khai để lấy danh sách game và một MCP server để agent AI truy vấn cùng dữ liệu đó. Không cần khóa API hay đăng nhập.

API danh sách game

GET https://lyphucthien.vercel.app/api/games trả về JSON gồm success, games và errors. Mỗi game có id, name, status (on hoặc soon), type, description, image, order và features (nhóm chức năng).

curl -s https://lyphucthien.vercel.app/api/games

Đặc tả đầy đủ nằm ở /openapi.json (OpenAPI 3.1).

MCP server

Endpoint: https://lyphucthien.vercel.app/mcp (cũng có tại /.well-known/mcp). Giao thức Streamable HTTP, gửi JSON-RPC bằng POST, không cần xác thực. Có hai tool chỉ đọc:

  • list_games: liệt kê game hỗ trợ, có thể lọc theo status và query.
  • get_key_instructions: các bước lấy key, thời gian chờ và đường dẫn trang lấy key.
curl -s https://lyphucthien.vercel.app/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Lưu ý về key

Key chỉ được cấp trên trình duyệt của người dùng sau khi họ hoàn thành link rút gọn, nên agent không thể lấy key thay người dùng. API kiểm tra key dành riêng cho script LPT Hub và không thuộc API công khai.

Tệp dành cho agent

/llms.txt mô tả khi nào nên dùng LPT Hub, /sitemap.xml liệt kê các trang, và trang chủ trả về Markdown khi gửi Accept: text/markdown.
