About LPT Hub

LPT Hub is a free key system for a Minecraft server and the LPT Hub script. The goal of the project is to let everyone try and use these tools without paying or creating an account. You just open the key page, pick a short link, complete it, and get your key right on the page.

How the project works

Each time you complete a short link (Work.ink, Link 4m or Link 4 Sub), the server checks that you followed the proper flow and then issues a key. Each device gets 1 key every 3 hours. One key works for both the Minecraft server and the LPT Hub script, and for the script the key is tied to one device and expires 3 hours after its first use.

Why there are short links

Short links help cover the cost of running the project, which keeps keys free for users. These sites are run by third parties and have their own policies, so be careful with the ads shown on them.
